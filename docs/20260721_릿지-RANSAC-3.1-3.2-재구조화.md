# 릿지-RANSAC 파이프라인 3.1/3.2 재구조화: 이론과 코드 방향성

작성일: 2026-07-21

## 0. 배경과 핵심 쟁점

6차 3변수 동차다항식(계수 p = 28) 곡면 적합에서, RANSAC 최종 모델로 가기 전 단계인
3.1(릿지·L-curve·CD/HD 진단)과 3.2(RANSAC·로컬 최적화)를 어떻게 재구조화할지가 문제였다.

논의의 출발점은 **샘플 크기를 작게 시작할지 크게 시작할지**의 대립이었다.

- **작은 샘플 시작 (본인 안):** RANSAC의 가설-검증 철학을 3.1부터 반영. 오염되지 않은
  부분집합으로 λ와 곡선을 본다.
- **전체 점 시작 (조언 안):** Sobolev 릿지 정규화가 강해 λ 추정이 샘플 크기에 둔감하므로,
  전체 점으로 안정적으로 추정하고 아웃라이어 정제는 3.2로 미룬다.

결론: 이 대립은 **"아웃라이어를 어느 단계에서 처리하느냐"**의 문제로 환원되며,
이분법이 아니라 **역할 분담**으로 양립시킨다.

## 1. 조언 논거의 검토

"Sobolev 릿지는 사이즈 무관하게 잡아놔서 전체점으로 해도 수렴한다"는 주장은
부분적으로만 옳다.

1. **λ의 스케일 의존성.** 릿지 해 `β̂ = (XᵀX + λR)⁻¹Xᵀy`에서 `XᵀX`는 n에 비례해 커지지만
   `λR`은 고정. 유효 정규화 강도 λ/n이 n에 의존하므로, 작은 샘플과 큰 샘플에서 최적 λ가
   다르게 나온다. → 최종 모델을 작은 샘플로 갈 것이므로 큰 샘플 λ 튜닝은 스케일이 어긋난다.
2. **아웃라이어의 릿지 오염.** 릿지는 L2 손실이라 부드러움(곡률)은 지키지만 위치 편향은
   못 막는다. 강한 아웃라이어 몇 개가 λ 추정과 L-curve 코너 위치를 왜곡할 수 있다.
3. **CD/HD의 민감성.** 특히 HD는 아웃라이어에 극단적으로 민감. 전체 점 HD는 사실상
   아웃라이어 거리 측정이 되어 3.1 진단 지표로서 신뢰도가 낮다.

→ 릿지가 n으로 정규화되어 있어도(이미 적용함) 위 세 가지 이유로 전체 점 λ*를
"기준"으로 삼기는 어렵다.

## 2. 유효 자유도(df)를 비교 좌표계로

### 2.1 정의

릿지 hat 행렬 `H_λ = X(XᵀX + nλR)⁻¹Xᵀ`에 대해 `df(λ) = tr(H_λ)`.
R을 화이트닝하면 SVD로:

```
df(λ) = Σᵢ σᵢ² / (σᵢ² + nλ)      (i = 1..p)
```

각 항 `sᵢ ∈ (0,1)`은 "i번째 주성분 방향을 몇 % 살리는가"이며, df는 28개 계수 중
**데이터가 실질적으로 결정하는 자유도의 총합**이다.

### 2.2 예시 (p = 28)

- **λ→0:** 모든 sᵢ→1, df→min(n, 28). n=30이면 df≈28, 거의 보간이라 아웃라이어 하나에도 요동.
- **적당한 λ:** σᵢ²가 [100,10,1,0.1,…]로 감쇠하고 nλ=1이면 sᵢ=[0.99,0.91,0.5,0.09,…]로
  df≈15. "28계수지만 실제로는 15-파라미터처럼 행동". 상위 곡률 성분(작은 σᵢ)이
  Sobolev 벌점에 눌린 상태.
- **λ→∞:** R의 영공간 차원(저차 성분 수)으로 수렴.

### 2.3 핵심 직관 — 크기 간 이식의 좌표계

**λ를 고정하지 않고 df를 고정한다.** n=200 전체점에서 df*=15가 나왔다면,
n=30 소샘플에서도 `df(λ; Xₙ) = df*`가 되도록 λ를 역산해 맞춘다. df는 λ의 단조감소
함수라 역산이 유일. λ 값 자체는 두 경우 크게 다르지만(소샘플 쪽 스펙트럼이 열악),
모델이 쓰는 복잡도는 동일하게 유지된다. → **λ 이식 문제를 아예 없앤다.**

### 2.4 주의: n ≈ p 영역

n = 28~43은 p = 28에 대해 거의 보간 영역. 이 영역에서 `XᵀX/n` 스펙트럼은 n에 따라
질적으로 달라지고(최소 고유값이 0에 붙어 조건수 폭발), λ의 역할이 "평활화"에서
"분산 억제"로 바뀐다. λ/n 스케일링만으로는 이식이 보장되지 않으므로,
**앙상블은 반드시 목표 크기에서 돌리고, 전체점 df*는 참고치(anchor)로만 쓴다.**
L-curve 코너도 이 영역에서는 뭉개지므로, 소샘플에서는 단일 코너값에 의존하지 말고
곡선군을 겹쳐 그려 코너 위치의 산포를 보고한다.

## 3. 3.1 재구조화 — 진단 단계

역할: 아웃라이어를 *제거*하는 게 아니라 *영향을 진단*한다.

### 세팅

- **(주) 목표 크기 앙상블:** n = 28~43 범위에서 랜덤 부분집합 20~50회 추출,
  각각 L-curve/CD/HD를 그리고 df*(및 λ*)의 분포를 본다. 단일 샘플의 우연한 오차는
  반복으로 해소.
- **(대조) 전체점 baseline:** 전체점 릿지도 한 번 돌려 df*를 같이 얹는다. 이는
  "아웃라이어 포함 시 어디로 끌려가는가"의 대조군.
- **비교 축은 df.** raw λ가 아니라 df로 비교하면 n이 달라도 직접 비교 가능.
  전체점 df*=18인데 소샘플 앙상블 df* 중앙값도 17~19면 → 정규화가 크기 불변으로
  작동한다는 조언 측 주장의 직접 검증.

### 3.1의 산출물 (→ 3.2 인터페이스)

1. **df\*** — 앙상블 중앙값 (모델 복잡도 목표)
2. **df\*의 산포** — 강인성 지표
3. **전체점 대비 괴리** — 아웃라이어 영향의 정량 지표. 이것이 3.2의 n 선택 기준이 된다.
4. **σ̂ 초기값** — 앙상블 잔차 분포에서 뽑은 로버스트 스케일 (3.2 τ 설정용 부산물)

## 4. 3.2 재구조화 — RANSAC + 로컬 최적화

### 4.1 무엇을 물려받는가

λ 값이 아니라 **df\* 하나**를 받는다. RANSAC 각 반복의 minimal set은 크기·조건수가
매번 다르므로, λ는 반복마다 그 샘플의 X에 대해 `df(λ)=df*`를 풀어 재산출한다.
뉴턴법/이분법 몇 스텝, tr은 SVD 한 번으로 저렴. **df 축을 쓴 진짜 이유 = 이식 문제 제거.**

### 4.2 샘플 크기 n 결정

RANSAC 이론상 무오염 샘플 확률은 `wⁿ`이라, n=43·w=0.8이면 `wⁿ≈7e-5`로 순수 샘플을
못 뽑는다. 릿지가 들어가면 관점을 바꾼다 — **"완전히 깨끗한 샘플"이 아니라 "릿지가
견딜 만큼만 오염된 샘플"**을 뽑으면 된다.

- 3.1 괴리가 작았다 → 릿지 오염 내성 검증됨 → n을 크게(40대) 가도 됨.
- 3.1 괴리가 컸다 → n을 28 근처로 내리고 반복 수로 승부.

즉 **3.1의 괴리 지표 = 3.2의 n 선택 기준**.

### 4.3 반복 수 k — 허용 오염 기반 이항 모델 (권장)

고전식 `k = log(1-p)/log(1-wⁿ)`은 "성공 = 완전 무오염"이라 릿지에서 과도하게 보수적.
성공을 **"샘플 n개 중 아웃라이어 m개 이하"**로 재정의:

```
P_good = Σⱼ₌₀ᵐ C(n,j) (1-w)ʲ wⁿ⁻ʲ
k = log(1-p) / log(1 - P_good)
```

**m은 3.1에서 이미 측정한 값** — 전체점 vs 앙상블 괴리 실험이 곧 "df* 릿지가 오염
몇 %까지 버티는가"의 측정이므로, 허용 오염률 × n = m.

예시: n=40, w=0.8. m=0(고전)이면 `P_good≈1.3e-4`로 k가 수만 회. m=4 허용이면
`P_good≈0.63`으로 k≈8회. → 릿지 내성이 반복 수를 지수적으로 절약.

운용: 초기 보수 w에서 시작 → 최고 모델 인라이어 비율로 w 갱신 → k 재계산 →
k 도달 또는 n_iter 상한에서 종료 (적응형).

논리 구조: **df* → (3.1 허용 오염) m → k**의 2단 구조. k를 df로 직접 정하거나
고정 n_iter로 두지 않는다. (고정 n_iter는 예산 상한으로만.)

### 4.4 인라이어 판정 (스코어링)

- 잔차는 가능하면 기하 근사 거리(Sampson 거리류). *(현재 구현이 대수적 잔차인지
  기하 근사인지 확인 필요 — τ 설정부가 달라짐.)*
- 임계값 τ는 고정 상수보다 로버스트 스케일 기반: `σ̂ = 1.4826·MAD`, `τ = 2.5·σ̂`
  (MSAC/MLESAC 표준). σ̂ 초기값은 3.1에서 물려받음.
- 점수 함수는 인라이어 카운트(고전)보다 **절단 잔차 합(MSAC)** 권장. 카운트는
  τ 근처에서 불연속이라 튜닝에 민감, MSAC이 완화.

### 4.5 로컬 최적화 = "중심 찾기" (LO-RANSAC)

최고 점수 모델 갱신 시마다: 그 인라이어 집합 전체로 릿지 재적합(λ는 df*로 재역산)
→ 인라이어 재판정 → 수렴까지 2~3회. 인라이어 집합은 minimal set보다 훨씬 크므로
df* 역산이 자동으로 λ를 약하게 조정. 가중치를 넣으려면 이 단계에서 IRLS로
Huber/Tukey 가중 → 사실상 "RANSAC으로 초기화한 M-추정".

### 4.6 3.2에서 튜닝할 것 / 안 할 것

- **고정 (3.1에서 결정):** df*, σ̂ 초기값. 3.2에서 다시 건드리면 단계 분리가 무너짐.
- **튜닝:** 반복 수 k(적응형 종료), τ 배수(2.0/2.5/3.0), LO 발동 조건, IRLS 가중 함수.

### 4.7 최종 미세 λ 최적화

RANSAC 종료 후 확정 인라이어 집합에서 df* 주변 좁은 구간(df*±2)만 CV/L-curve로
미세 조정. 탐색 범위가 3.1에서 좁혀져 있어 비용 거의 없음. 이것이 최초에 언급한
"람다 미량 최적화"의 자리.

## 5. 추가 구현 요소

- **퇴화 샘플 검사:** minimal set X의 조건수/최소 특이값 검사 후 열악하면 기각.
  점들이 국소에 뭉치면 동차다항식 적합이 퇴화 → 저비용·고효과.
- **유도 샘플링(PROSAC식):** 3.1 앙상블 잔차가 작았던 점에 샘플링 확률 가중.
  장기 계획의 "ridge 고려 샘플링"의 구현 지점.
- **가중치 갱신:** 위 4.5의 IRLS.

## 6. 실험 프레임워크

기본값을 고정하고 한 축씩 변화(OFAT), 상호작용 의심 쌍만 소규모 격자.
각 셀은 시드 20회 반복, 중앙값 ± IQR 보고.

| 조작변수 | 수준 예시 | 주 관찰지표 |
|---|---|---|
| n | 28 / 34 / 43 | 성공률, k 실측치 |
| 허용 오염 m | 0 / 3.1측정값 / ×2 | k, 최종 CD/HD |
| τ 배수 | 2.0 / 2.5 / 3.0 | 인라이어 집합 안정성 |
| 점수 함수 | count / MSAC | 시드 간 분산 |
| LO + IRLS | 없음 / Huber / Tukey | 최종 CD/HD, λ_final |
| 샘플링 | 균등 / 유도 / +퇴화검사 | 첫 성공까지 반복 수 |

관찰지표 정의:

1. **최종 CD/HD** — 가능하면 홀드아웃 또는 합성 GT 대비.
2. **인라이어 집합 안정성** — 시드 20회 간 인라이어 집합 Jaccard 유사도.
   낮으면 해가 다봉성이라는 경고.
3. **λ_final(=df_final) 분포** — 3.1 df*와 일치하는지로 파이프라인 정합성 검증.
4. **실측 k와 벽시계 시간.**

상호작용 확인이 필요한 쌍:

- **n × m** — 둘 다 k를 지배.
- **τ × 가중함수** — 둘 다 인라이어 경계를 정의.

기본 세팅 예: n=34, m=3.1값, τ=2.5, MSAC, Huber, 균등 샘플링.
결론은 "어떤 세팅이 CD/HD와 안정성의 파레토 전선에 있는가"로 떨어진다.

## 7. 요약 흐름

```
3.1 (진단)
  목표 크기 앙상블(주) + 전체점(대조)
  → df 축으로 비교
  → 산출: df*, 산포, 괴리, σ̂ 초기값

3.2 (RANSAC + LO)
  n         ← 3.1 괴리로 결정
  λ         ← 매 반복 df* 역산
  m, k      ← 3.1 괴리 → m → 이항모델 k (적응형)
  판정      ← MSAC + MAD 기반 τ
  정제      ← LO 재적합 (+IRLS 가중)
  최종 λ    ← df* 근방 미세 튜닝
```

두 조언의 논점(작은 샘플 안정성 vs 전체점 강인성)이 각 단계에 자연스럽게 흡수된다.

## 8. 확인 필요 사항 (다음 논의)

- 현재 잔차 구현이 **대수적 잔차**인지 **기하 근사 거리**인지 (4.4의 τ 설정에 영향).
