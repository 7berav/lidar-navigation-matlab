## 0. 한 줄 요약

> 6차 동차다항 곡면 릿지 피팅에서 **유효자유도(df)를 좌표계로** 삼아, 초기 자세/위치 추정에는 **4차 기저 + 고정 λ RANSAC**이 충분(오히려 표본효율상 유리)함을 보이고, 이를 **가림(occlusion) + 아웃라이어** 환경에서 검증 중.

---

## 1. 핵심 메시지 (세미나 스토리 라인)

1. **df = tr(H_λ)를 비교 좌표계로.** raw λ는 표본크기·차수마다 의미가 달라지지만 df는 "데이터가 실제로 결정하는 복잡도"라 크기·차수를 가로질러 직접 비교 가능.
2. **정규화의 크기 불변성은 저 occlusion에서만 성립.** 소표본 df\*와 전체점 df\*가 occ≤40%에선 근접, occ≥50%에선 괴리 급증 → 이 괴리가 표본크기·강건성의 진단량.
3. **낮은 df\*는 "숨은 점까지 포함한 CD"의 부작용.** 보이는 영역만 보면 df~20을 원하지만(디테일), 완전표면 CD는 관측 못 한 절반을 벌하므로 df~8(블롭)로 편향. → 목적별로 λ_hyp(보이는 적합, df 높음) vs λ_refit(복원, df 낮음)이 갈림.
4. **자세추정엔 4차면 충분, 오히려 유리.** 같은 df로 맞추면 차수는 거의 무관(4차≈6차 CD). 그런데 4차는 minimal sample이 21점(6차 39점)이라 **RANSAC 무오염표본 확률 wⁿ이 56~614배** 높음 → 반복수 지수 절약.
5. **엔드투엔드 최적 λ는 1e-2** (3.1 소표본 최적 1e-1보다 한 자릿수 아래). RANSAC의 local refit이 전체 인라이어(~2800점)로 재적합하므로 refit regime에서 λ가 작아짐 → **λ_hyp≠λ_refit 실증**. 릿지가 OLS를 이기고, 과정규화(λ≥1e-1)는 악화.

## 2. Section 3.1 (완료) — 릿지 df 진단

### 검증된 것
- **df(λ) 단조감소**, λ→0에서 df→min(n, p) (6차 p=28, 4차 p=15). 7개 occlusion·전 도형 확인.
- **크기 불변성 붕괴점**: hexagon 기준 df\* 괴리(subset−full) = occ10 −0.7 → occ50 −5.9 → occ70 −14.2. 도형 종합 df\* basin은 occ20~50%에서 **8~13** 범위로 겹침.
- **CD 3분할의 필요성**: order-6, occ30에서 최적 df가 관측영역별로 갈림 — 보이는영역 df~20, 완전표면 df~15, 숨은영역 df~6. → 완전표면 CD가 df\*를 낮게 끌어내림.
- **4차 vs 6차**: hexagon occ30에서 4차 CD\* 0.197@df7.9 ≈ 6차 0.210@df15. **같은 df(≈9)로 맞추면 두 차수 CD 거의 동일** → 차수보다 df가 지배.

### 결정 (→ 3.2 인터페이스)
- **차수**: 자세추정/가설 = **4차**, 최종 refit = 6차 (코스-투-파인).
- **λ 고정** (런타임 df 적응 불필요): 같은 표본크기 안에서 λ 고정 시 draw별 df 산포 CV<9%(±1). RANSAC은 n 고정이라 이식 문제 없음.
- **df는 진단 도구**이지 런타임 파라미터가 아님.

## 3. Section 3.2 (완료 — 단, λ=1e-1 기준 예비본) — RANSAC 아웃라이어·수렴

### 세팅
- 4차 기저, occ=0.30 가림, maxIter 상수 고정(1000; saturation용 3000), 적응 샘플링(freezeW/Omega=false), 이론 N은 참고 출력만.
- OFAT(한 축씩): 기준셀 hexagon·occ0.3·ε0.2·λ1e-1, seed 20회.

### 결과 (핵심 수치)
- **λ ablation (hexagon, ε=0.2)**: **λ=1e-2가 최적** — F1 0.960 / CD 0.064. cf. OLS 0.928/0.096, λ=1e-1 0.857/0.175, λ=1e0 0.716/0.526. → **내부 최적 확인**.
- **균일 아웃라이어 강건성 (λ=1e-1)**: F1 0.905→0.790 (ε 0→40%), 완만 저하. precision 주로 하락, recall 안정.
- **구조적(2물체)이 더 어려움**: ε=0.4에서 균일 F1 0.79/CD 0.22 vs 구조적 0.67/0.45. 구조적은 precision이 붕괴(두 번째 도형이 국소적으로 인라이어처럼 보임).
- **오프셋 효과**: F1은 불변(~0.735)이나 CD는 급증(겹침 0.24 → 분리 0.61) — 멀리 있는 오분류 점이 표면을 크게 왜곡.
- **가림 스킴**(물체별 vs 전역): 인접 배치에서 거의 동일(F1 0.735 vs 0.722).
- **수렴 saturation**: maxIter 1000 vs 3000 → F1 0.857 vs 0.859 (동일). **1000이면 충분**.
- **6차 post-hoc refit**: 완전표면 CD 무이득(cd6>cd4) — 3.1 occlusion 결론과 정합.

### ⚠️ 예비본 주의
eps·도형·2물체 sweep은 모두 **baseLam=1e-1(suboptimal)**로 돌았음. λ=1e-2 최적은 **hexagon/ε=0.2 한 점에서만** 검증됨. → 아래 TODO 1·2로 확정 필요.
