## 1. 정정 사항 (중요 — 이전 결론을 뒤집는 것들)

### 1.1 Sobolev 페널티에는 널스페이스가 있다 → λ→∞ 극한은 **구(球)**

한때 "λ↑ 이면 β 가 0 으로 수축해 f→0, 잔차→1 이라 τ 게이트가 닫힌다"고 서술했는데 **틀렸다.**

`regressionFourthOrder:42` 가 l=0 항을 면제한다(order 4 가중 = `[1.00×9, 0.30×5, 0.00×1]`).
미페널티 기저함수는 정확히 **r⁴** 이므로 극한 모델은 `f = c·r⁴ = 1`, 즉 **최적 구**다.

hexagon occ=0.30 실측 (λ = 0 → 1e6): ‖β‖ 2.814 → **0.486**, 널스페이스 몫 0.464 → **1.000**,
median|f−1| 0.228 → **0.374**, r/τ → **0.831**. 잔차는 1 이 아니라 "최적 구 잔차"에서 포화하고
게이트는 **원리적으로 닫히지 않는다.**

→ 결론(게이트 안전, τ·잔차 정의 그대로 유지)은 같지만 이유가 다르고, 새 이유가 더 쓸모 있다:
**과정규화는 무(無)가 아니라 구로 간다.** `axis_gap_fit → 1`(블롭)은 수치 아티팩트가 아니라
널스페이스 극한 그 자체이며, **CD 가 자세 손실을 거의 벌하지 않는 이유**이기도 하다.
`ransac_diagnostics_image` 의 occ70·λ=1e-1 패널에서 타원체로 붕괴한 등위면이 눈으로 보인다.

### 1.2 중심 편향은 occ 0.3 에서 안 보이고 0.5 부터 급증한다

"중심 편향 1~2% 로 미미"라고 했던 건 **occ=0.30 한 점의 얘기**였다. occ 축을 열고 보니
(실패 제외, 양 fold 일치):

| occ | e_par (가림방향) eval / tuning | \|e\| |
|---|---|---|
| 0.1 | −0.003 / −0.003 | 0.006 |
| 0.3 | +0.002 / −0.005 | 0.013~0.017 |
| 0.5 | **+0.080 / +0.066** | 0.07~0.10 |
| 0.7 | **+0.116 / +0.110** | 0.13~0.14 |

→ **"가림이 있으면 중심이 특정 방향으로 밀린다"는 최초 예측이 맞았다.** 부호도 예상대로 가시면(+z).
따라서 "위치는 강건, 자세만 약함" 이 아니라 **위치와 자세가 occ 0.4 근방에서 거의 동시에 무너진다.**

### 1.3 maxIter 1000 은 λ\* 에서 포화가 아니다

문서의 "1000 이면 충분(F1 0.857 vs 0.859)" 은 **λ=1e-1 예비본 측정**이다. λ\*=1e-2 에서는:

| | F1 | cd_all | cd_occ | n_conv 중앙값 / p90 |
|---|---|---|---|---|
| 1000 | 0.945 | 0.078 | 0.084 | 376 / **817** |
| 3000 | 0.952 | **0.061** | **0.073** | 954 / **2692** |

결정적 근거는 **`n_conv` p90 이 예산에 비례해 커진다**는 것(817 → 2692). 수렴했다면 평평해야 한다.
λ=1e-1 에서 포화했던 건 과평활화로 모델 공간이 좁아서였고, λ\* 에서는 더 풍부해 계속 개선을 찾는다.
→ 현재 주요 수치는 **일관되게 약간 보수적**. 비교는 유효하나 최종 예산은 재검토 필요.

### 1.4 자세 지표의 생존편향

실패 시드를 뺀 중앙값으로 보고했는데, occ 0.6~0.7 은 실패율이 45~90% 라 살아남은 소수만 본 것이었다.
전체 시드로 집계하도록 고쳤다(다른 지표는 실패 제외 유지). 고친 뒤 두 fold 가 occ≥0.4 에서
**λ 효과의 부호까지 어긋난다** → 자세 주장은 **occ ≤ 0.3 으로 한정**.

### 1.5 배경 평면이 "가장 쉽다"는 ε ≤ 0.3 한정

ε≤0.3 에서는 precision 정확히 1.00(닫힌 등위면이 무한 평면을 흡수 못 함)인데,
**ε=0.4 에서 실패율 60% 로 뒤집힌다.** 살아남은 40% 는 여전히 완벽(F1 0.97).
완전한 이봉이라 중앙값만 보면 "F1 0.55" 로 뭉개진다.

| 지표 | 규약 |
|---|---|

| `cd_occ` | `occ_empty` 비율을 **반드시 동반**. 복원면이 hidden 영역에 없으면 실거리가 아니라 bbox 대각 페널티다. 3.1 은 낮은 occ 에서 40~70% 가 페널티였고 그 결과 "강한 정규화가 유리"라는 착시가 났다(λ↑ 이면 구가 되어 hidden 을 반드시 채우므로 회피). **3.2 는 전 occ 에서 0%** — 차이는 중심 최적화. |

## 3. 3.3 정합 아키텍처 — 이번 세션의 핵심 방향 결정

### 3.1 문제 제기

단일 프레임 자세 오차가 occ 0.5 에서 51°(무작위 60° 근방)인데 정합이 가능한가?

### 3.2 답 — 가능하다. 단 **정합이 자세 추정을 경유하면 안 된다**

우려의 전제는 "프레임마다 자세를 뽑아 합친다"인데, 그 경로면 불가능한 게 맞다.

**현실적 regime**: 단일시점 LiDAR 는 자기가림으로 원리적으로 ~50% 가 안 보인다.
즉 현실적 단일 프레임은 **occ ≈ 0.5** 이고 거기서는 실패율 **0~5%**, 중심 오차 **7~10%**, 자세 51°.
**중심 7~10% 는 ICP 초기값으로 충분히 좋다.** 이게 핵심.

```
프레임 k:  RANSAC 암시적 적합 → 중심 ĉ_k (7~10%) + 형상 사전
    ↓
프레임 간 회전: 중심 정렬로 초기화한 Kabsch/ICP
    - 병진이 풀려 있어 SO(3) 만 탐색 → 조건수 개선
    - tumbling 은 프레임률 대비 느림 → 프레임 간 회전이 작음
    - **절대 자세를 단일 프레임에서 뽑을 필요가 없음**
    ↓
누적 → 유효 가시율 상승 (occ_effective 하락)
    ↓
누적 점군에 재적합 → 위치·자세 둘 다 살아남
```

`nnDist` + `svd` 로 ~30줄. Computer Vision Toolbox·어텐션·deep ICP 불필요.
이미 `occlusion_lambda_evaluation_design §3` 에 "tumbling → 다중 시점 누적 → 유효 가시율 회복"으로
적혀 있던 방향이다.

### 3.3 논문 서사

- **3.2**: 단일 프레임의 한계를 **정량화** — occ 0.4 가 위치·자세 공통 붕괴점, 원인은 가림 단독(50%) + 오염(+40%p)
- **3.3**: 누적이 그 한계를 넘는 메커니즘 — **자세 오차 vs 누적 프레임 수**가 무작위(60°)에서 내려오는 지점

단일 프레임 실패가 약점이 아니라 **동기**가 된다. 암시적 적합의 역할도
"회전 추정기"가 아니라 **"형상 모델 + 중심 앵커"** 로 정직하게 재배치된다.

## 4. 정합에 필요한 지표 — 장축만으로는 부족

### 4.1 DOF 셈

정합은 6 DOF. 장축 방향 = **2 DOF**(구면 위 한 점, 부호 무시). 남는 것 = **축 둘레 roll 1 DOF**.
현재 `theta_axis` 는 그 2 DOF 만 잰다. roll 이 유의미한지는 **물체 대칭이 결정**한다:

| 도형 | 대칭군 | 장축 | roll | 장축만으로 충분? |
|---|---|---|---|---|
| cylinder | D∞h | 있음 | 연속 대칭 → 정의 안 됨 | ✅ 충분 |
| hexagonal prism | D6h | 있음 | 60° 주기 존재 | ❌ roll 필요 |
| cube | Oh | **없음**(2차 등방) | — | ❌ 장축 자체가 무의미 |

### 4.2 추가할 지표 (우선순위)

**1순위 — ADD-S** (6D pose 표준, Hinterstoisser)

```
ADD-S = (1/|M|) Σ_{x∈M} min_{y∈M} ‖ T̂x − T y ‖
```
- **대칭을 자동 처리**(cube 를 90° 돌려도 0) → 대칭군을 손으로 열거할 필요 없음
- 회전·병진을 **미터 하나로** 묶음 → 도킹 허용오차와 직접 비교
- 관례 기준 `ADD-S < 0.1×지름` 으로 **성공률** 보고 가능
- `nnDist` 재사용, 구현 5줄. **"정합 성능"의 헤드라인이 되어야 함**

**2순위 — 조화 계수 오차 `err_l`**

Fischer 기저는 **구면조화 분해**다(`levels = order:-2:0`, 레벨당 `2l+1` 개;
4차 = `H₄ ⊕ r²H₂ ⊕ r⁴H₀` = 9+5+1 = 15). 즉 **β 앞 9개(l=4 블록)가 degree-4 구면조화이고
회전에 대해 9×9 Wigner D 로 변환**된다. 방향 정보가 여기 다 있다.

**지금 자세를 등위면 점군의 2차 모멘트(공분산)로 읽는 것은 4차 정보를 통째로 버리는 것**이고,
cube 에서 NaN 이 나오는 게 그 증거다. 싼 버전:

```
err_l = ‖β̂_l − β_gt,l‖ / ‖β_gt,l‖    for l = 4, 2, 0
```
`err_0`=크기, `err_2`=신장(지금 theta_axis 가 보는 것), **`err_4`=4차 형상·방향(roll 포함, cube 에서도 정의)**.
**"4차 기저가 자세추정에 충분한가"의 직접적인 답이 여기서 나온다.** 구현 10줄.

**3순위** — l=4 블록에서 Wigner D 로 정식 회전 추정 → roll·`θ_geo`(대칭군 최소화). 구현량 큼, 필요시.

> 현재 "4차면 자세추정에 충분" 주장은 **아직 2차 모멘트로만 검증된 상태**다. 4차 기저가 실제로
> 담고 있는 정보를 안 본 것이라 유리하게도 불리하게도 결론이 바뀔 수 있다.

## 5. 솔버 현황 — **바닐라 아님**

`PoliNavigationSolver3_3_FischerRansac_MC.m` 은 이미:

```matlab
idx = randsample(1:N, k, true, omega);        % ω 기반 유도 샘플링
omegaj = exp(-r.^2/(2*sigma0^2));             % 소프트 가우시안 점수(하드 카운트 아님)
Sj = mean(omegaj);                            % MLESAC 류 점수
omega = (Ssum/(Ssum+SjLoc))*omega + (SjLoc/(Ssum+SjLoc))*omegajLoc;  % ω 누적 갱신
w = 0.800*w + 0.200*sum(omega(inMaskj))/sum(omega);                  % 인라이어율 EMA
```

= 유도 샘플링 + 소프트 스코어링 + 국소 최적화 (LO-RANSAC 계열 + MLESAC 스코어링 + PROSAC 식 적응 리샘플링).

**남은 개선 여지:**
1. **국소 재적합의 IRLS** — `DisplacementLocal` 이 하드 인라이어에 **균등 가중** 릿지를 건다.
   Huber/Tukey 는 `20260721 §4.5` 제안이나 미구현. **여기가 진짜 여지.**
2. **퇴화 표본 기각** — 21점 조건수 검사 없음(`§5` 제안). 점이 국소에 뭉치면 동차다항 적합이
   퇴화하는데 그 반복이 낭비된다. 싸고 효과 클 가능성.
3. **ω ablation 미실행** — `ransacPar.sim.freezeOmega` 플래그가 있는데 한 번도 안 돌렸다.
   PPT S13 에 "ω-update ON vs OFF" 로 약속된 항목. **지금 ω 가 얼마를 벌어주는지 모른다.** 2셀.
